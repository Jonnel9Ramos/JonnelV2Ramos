LINEA DE TIEMPO HITOS DE VR

  1. 1962 - El sensorama: Se crea la primera maquina interactiva
  2. 1968 - La espada de Damocles: Se desarrolla el primer visor conectado a una computadora
  3. 1987 - Nace el termino "VR": Se populariza el concepto
  4. 1995 - Nintendo Virtual Boy: Se lanza la primera consola para consumo masivo
  5. 2012 - Oculus Rift: Se lanza el primer visor de realidad virtual de consumo
  6. 2014 - Facebook adquiere Oculus VR
  7. 2016 - Año de la VR comercial: Lanzamiento masivo
  8. 2019 - Oculus Quest: Se lanza el visor de realidad virtual independiente
  9. 2024 - Apple Vision Pro: Se lanza el visor de realidad virtual de Apple
  10. 2026 - Ecosistema inalambrico y mixto: La industria se consolida con la realidad mixta y la conectividad inalambrica

CONFIGURA Y USA POR PRIMERA VEZ TU VR

  1. Despeja el área de juego
  2. Carga el visor y asegúrate de que esté bien conectado
  3. Encender el dispositivo
  4. Ajusta las lentes y el volumen
  5. Conecta a la red Wi-Fi
  6. Configura el sistema de seguridad
  7. crea tu perfil de usuario
  8. Descarga aplicaciones y juegos
  9. Realiza el tutorial de movimiento y control
  10. Toma descansos regulares
